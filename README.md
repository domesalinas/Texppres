## 📋 Descripción del Proyecto
**Texppres** es una solución computacional desarrollada para la materia de **Programación III**, diseñada para optimizar los procesos de 
transporte, acopio y distribución de mercancías y encomiendas a nivel urbano y regional. 

El sistema busca resolver los cuellos de botella en bodega, la falta de trazabilidad en tiempo real y la ineficiencia en la asignación de
rutas mediante una plataforma centralizada y automatizada. Permite registrar unidades de transporte de carga, programar itinerarios de 
despacho, rastrear la ubicación/estado de los paquetes y medir el rendimiento operativo a través de indicadores KPI.
